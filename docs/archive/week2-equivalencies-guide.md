# Week 2: Cross-Institution Equivalency Mappings

## Overview
This document explains the 50 equivalency mappings that connect alternative credits to TESU course codes.

## Mapping Structure

Each equivalency mapping includes:
- **alt_credit_id**: Links to the alternative credit
- **institution_id**: TESU institution ID
- **institutional_course_code**: TESU course code (e.g., 'ENC-101')
- **institutional_course_name**: Full TESU course name
- **credits_awarded**: How many TESU credits granted
- **level**: 100/200/300/400 level
- **gened_category_code**: Which gen-ed requirement it satisfies (if any)
- **requirement_area**: 'gened', 'major', 'elective', 'free_elective'
- **confidence**: 1.0 = official transfer guide
- **source_documentation**: URL to official TESU documentation
- **last_verified_date**: When mapping was last confirmed

## Confidence Scores

All mappings have **confidence = 1.0** because:
- Based on official TESU transfer guides
- CLEP/DSST: Long-standing TESU acceptance policy
- Sophia: Official "Sophia Pathways to TESU" partnership
- Study.com: Official "Study.com Pathways to TESU" partnership

Lower confidence (0.7-0.9) would be used for:
- Inferred equivalencies without official documentation
- New courses not yet in transfer guides
- Conditional acceptances requiring additional review

## Using These Mappings

### In the Optimizer
```typescript
// Query equivalencies for a requirement
const { data: options } = await supabase
  .from('cross_institution_equivalencies')
  .select(`
    *,
    alt_credits (*)
  `)
  .eq('institution_id', tesuId)
  .eq('gened_category_code', 'WRITTEN_COMM');

// Returns: 4 options (CLEP x2, Sophia x2)
```

### In Degree Templates
Each slot can specify:
- **preferred**: The recommended option (usually cheapest or fastest)
- **alternatives**: Other valid options from equivalencies

Example:
```json
{
  "slotId": "term1-slot1",
  "requirementArea": "WRITTEN_COMM",
  "minCredits": 6,
  "preferred": {
    "type": "alt_credit",
    "sourceCode": "CLEP",
    "identifier": "COLLEGE_COMPOSITION"
  },
  "alternatives": [
    {
      "type": "alt_credit",
      "sourceCode": "SOPHIA",
      "identifier": "ENG-101"
    },
    {
      "type": "alt_credit",
      "sourceCode": "SOPHIA",
      "identifier": "ENG-102"
    }
  ]
}
```
